Questions Before PIR / PUR / ETICS Facer Review

Is this an insulation board product page?

No. This page is about fiberglass facer directions for PIR / PUR / ETICS insulation board systems. GRECHO supports application review, sample coordination and technical document review for selected facer directions.

How is this page different from the Mineral Wool Solution Hub?

This page focuses on PIR, PUR and ETICS insulation board systems, including foam-core compatibility, exterior-facing direction and system compatibility review. The Mineral Wool page is framed around mineral wool board facer review.

Can GRECHO help review facer directions before final specification?

Yes. A concise application brief can support early direction review before every specification, coating route or document request is locked.

What documents can be requested for PIR / PUR / ETICS facer review?

Product briefs, color TDS where relevant, full TDS by review, fire-related documents by scope and safety or compliance documents can be requested through the form.
